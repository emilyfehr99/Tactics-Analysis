# Hockey Tactical Analysis System

A Python-based system for analyzing hockey systems, formations, and tactical patterns from player tracking data generated by the Computer-Vision-for-Hockey project.

## Overview

This system takes the player tracking data (JSON/CSV format) from your Computer-Vision-for-Hockey project and analyzes:

- **Formation Recognition**: Identifies common hockey systems like 1-3-1, 2-1-2, 1-2-2, etc.
- **Positional Analysis**: Analyzes player positioning relative to rink zones
- **Movement Patterns**: Tracks how formations evolve during play
- **Tactical Insights**: Provides analysis of team strategies and positioning
- **Visualization**: Creates interactive visualizations of formations and tactics

## Features

### Core Analysis Capabilities

- **Formation Detection**: Automatically identifies hockey formations from player positions
- **Zone Analysis**: Analyzes player distribution across offensive/defensive/neutral zones
- **Temporal Tracking**: Tracks how formations change throughout the game
- **Team Comparison**: Compares formation usage between teams
- **Statistical Analysis**: Provides metrics on formation effectiveness

### Supported Hockey Systems

- **1-3-1**: Power play and offensive zone formations
- **2-1-2**: Neutral zone trap and defensive formations  
- **1-2-2**: Standard defensive zone coverage
- **2-2-1**: Aggressive forechecking formations
- **1-4**: Defensive zone collapse
- **Custom Formations**: User-defined formation patterns

### Data Input

The system accepts data from:
- JSON tracking files from Computer-Vision-for-Hockey
- CSV files converted from the tracking data
- Real-time streaming data (future feature)

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run basic analysis on tracking data
python src/analyze_formations.py --input data/player_tracking.csv --output results/

# Run comprehensive tactical analysis
python src/tactical_analyzer.py --input data/ --output results/ --formations 1-3-1,2-1-2

# Generate interactive visualizations
python src/visualize_tactics.py --input results/ --output visualizations/
```

## Usage Examples

### Basic Formation Analysis

```python
from src.formation_detector import FormationDetector
from src.tactical_analyzer import TacticalAnalyzer

# Load tracking data
analyzer = TacticalAnalyzer('player_tracking.csv')

# Detect formations
formations = analyzer.detect_formations()

# Analyze specific system
system_analysis = analyzer.analyze_system('1-3-1')
print(f"1-3-1 formation used {len(system_analysis)} times")
```

### Zone-Based Analysis

```python
from src.zone_analyzer import ZoneAnalyzer

zone_analyzer = ZoneAnalyzer('player_tracking.csv')

# Analyze offensive zone positioning
offensive_stats = zone_analyzer.analyze_zone('offensive')
print(f"Average players in offensive zone: {offensive_stats['avg_players']}")

# Analyze neutral zone trap
trap_analysis = zone_analyzer.analyze_trap_formation()
```

### Movement Pattern Analysis

```python
from src.movement_tracker import MovementTracker

tracker = MovementTracker('player_tracking.csv')

# Track formation transitions
transitions = tracker.analyze_formation_transitions()
print(f"Most common transition: {transitions['most_common']}")

# Analyze player movement patterns
movement_patterns = tracker.analyze_player_movement()
```

## Configuration

### Formation Definitions

Define custom formations in `config/formations.yaml`:

```yaml
formations:
  1-3-1:
    description: "Power play formation"
    zones:
      offensive: [1, 3, 1]
      neutral: [0, 0, 0]
      defensive: [0, 0, 0]
  
  2-1-2:
    description: "Neutral zone trap"
    zones:
      offensive: [0, 0, 0]
      neutral: [2, 1, 2]
      defensive: [0, 0, 0]
```

### Analysis Parameters

Configure analysis parameters in `config/analysis.yaml`:

```yaml
analysis:
  frame_threshold: 10        # Minimum frames to confirm formation
  confidence_threshold: 0.7  # Formation detection confidence
  zone_tolerance: 0.1        # Zone boundary tolerance
  movement_threshold: 5.0    # Minimum movement to track
```
